Webhooks received

The signing service posts to /webhooks/esign whenever an envelope completes, seals, is declined, is voided or expires. Each delivery carries X-Esign-Signature: t=…,v1=…, which this records system checks against the shared secret before believing a word of it — and refuses if the timestamp is more than five minutes old, so a captured delivery cannot be replayed.

Payloads carry ids, statuses and hashes. There is no name and no record number in one; the sealed PDF itself is fetched afterwards over the authenticated API.
